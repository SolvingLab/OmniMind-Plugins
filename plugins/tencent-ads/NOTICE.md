This directory is an original Python standard-library adapter for the Tencent Ads Marketing API.

Interface facts are pinned to TencentAd/marketing-api-go-sdk v1.7.87, commit 81d6cc04b58d7d5a5ec9ad0137e43b3b6c52fde9, which is Apache-2.0. This package does not vendor the Go SDK source. The Apache-2.0 license text in LICENSE is the upstream LICENSE file from that commit, included because this adapter is offered under Apache-2.0.

OAuth parameter names are taken from https://developers.e.qq.com/docs/start as fetched on 2026-10-15. The sample token values in that page's response example are not copied here.
