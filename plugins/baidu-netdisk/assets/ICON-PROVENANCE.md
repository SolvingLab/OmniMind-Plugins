# 百度网盘 icon provenance

No brand icon file is shipped in this package.

Official brand-use page, fetched 2026-10-15 over HTTPS with certificate verification:

https://pan.baidu.com/union/doc/规范标准/品牌规范/使用/

That page says products which integrate the open platform must show the Baidu
Netdisk and open-platform marks, and that the actual mark files are issued
after a request to the platform. It also says the marks must not be used in a
product interface without authorization. This package therefore does not copy,
trace, or redraw the Baidu Netdisk logo.

Prototype row `proto:market:百度网盘` keeps the prototype BlocksIcon. BlocksIcon
is not a brand-icon acceptance. Do not borrow Google Drive, WPS, or another
cloud icon for this row.
