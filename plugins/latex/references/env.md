# Config

Manifest mcp_config env WEB_LATEX_MCP_WORKSPACE is required here and has no default.
Upstream workspace default ${HOME}/latex-workspace is rejected.
OVERLEAF_GIT_TOKEN and GITHUB_TOKEN are upstream-optional and are not referenced, so a missing token does not have to be present to parse this package.
Compilers named by the manifest and README: latexmk, tectonic. No compiler path was invented.
